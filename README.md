## Setup

```sh
git clone https://github.com/vivid-foods/app.git
cd app
```

```sh
pnpm install
npx expo start
# npx expo start -c --web
```

## Build

#### EAS Development Build (Android)

```sh
eas build --profile development --platform android
npx expo start --dev-client
```
